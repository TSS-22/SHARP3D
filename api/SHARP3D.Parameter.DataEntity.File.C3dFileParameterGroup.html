Remarks

Byte: 1 Reserved for parameter file use.

Byte: 2 Reserved for parameter file use.

Byte: 3 Parameter section size in 512 byte blocks.

Byte: 4 Processor type.

Value = 0x53 + processor type

Value (in decimal) = 83 + processor type

0x54Processor type 1: INTEL
0x55Processor type 2: DEC (VAX,PDP-11)
0x56Processor type 3: MIPS (SGI/MIPS)
