Remarks

The dimensions are the indices from the Fortran matrix of the parameter data, as they would appear in a classic matrix. For example: a matrix m*n, where m corresponds to Dimension0 and n corresponds to Dimension1. This is the meaning of the associated dimension and is provided for informational purposes.
