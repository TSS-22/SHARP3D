IsBaseElementPrimitive(Array)

Determines whether the base elements of a jagged or multi-dimensional array are of a primitive type.

public static bool IsBaseElementPrimitive(Array array)

Parameters

array Array

The input array to check. Can be a jagged array (e.g., int[][]) or multi-dimensional array.

Returns

bool

true if the innermost elements of the array are primitive types (e.g., int, char, bool); false if the array is null, empty, or the base elements are non-primitive (e.g., string, custom classes).

Examples

int[][] jaggedIntArray = new int[2][];
jaggedIntArray[0] = new int[] { 1, 2, 3 };
bool isPrimitive = IsBaseElementPrimitive(jaggedIntArray); // Returns true

Remarks

This method recursively drills down to the innermost element type of the array. For example:

  • int[][] returns true because the base element is int.
  • string[][] returns false because the base element is string.
  • char[][][] returns true because the base element is char.

IsBaseElementString(Array)

Determines whether the base elements of a jagged or multi-dimensional array are of type string.

public static bool IsBaseElementString(Array array)

Parameters

array Array

The input array to check. Can be a jagged array (e.g., string[][]) or multi-dimensional array.

Returns

bool

true if the innermost elements of the array are of type string; false if the array is null, empty, or the base elements are not string.

Examples

string[][] jaggedStringArray = new string[2][];
jaggedStringArray[0] = new string[] { "hello", "world" };
bool isString = IsBaseElementString(jaggedStringArray); // Returns true

Remarks

This method recursively drills down to the innermost element type of the array. For example:

  • string[][] returns true because the base element is string.
  • string[][][] returns true because the base element is string.
  • int[][] returns false because the base element is int.
  • object[][] returns false because the base element is object.
