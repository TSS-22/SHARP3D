Remarks

This struct stores 3D point data and analog data as lists of arrays.

Points: A list of C3dDataPoint arrays, where each array represents a frame of 3D points.

Analogs: A list of 2D float arrays, where each array represents a frame of analog data.

Equality: Two C3dData instances are considered equal if their Points and Analogs fields are equal.
