ParametersFromFileStreams(FileStream, ProcessorType, int, int)

Parses C3D parameter groups and parameters from a file stream.

public static List<C3dFileParameterGroup> ParametersFromFileStreams(FileStream c3dStream, ProcessorType processorFile, int pointerParameterSection, int pointerDataSection)

Parameters

c3dStream FileStream

The file stream of the C3D file.

processorFile ProcessorType

The processor type used in the C3D file.

pointerParameterSection int

The pointer to the parameter section in the C3D file.

pointerDataSection int

The pointer to the data section in the C3D file.

Returns

List<C3dFileParameterGroup>

A list of C3dParameterGroup parsed from the file stream.

Remarks

Empty groups (which have no parameters linked to them) are discarded. This is implemented due to Vicon potentially adding twice PROCESSING group, once empty and once with the actual parameters.
