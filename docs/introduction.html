Samples and Tests

You can find C3D samples on the C3D website. A large part of their set is used for testing this library and can befound in SHARP3D.Test.SampleFiles.

The expected results where extracted from C3D files automatically using ezc3d, they can therefore be subject to some problems. The values that were obviously wrongly read using ezc3d have been discarded or sanitized. When in doubt, binaries files where manually checked using Ghidra, ImHex and Qualisys Track Manager. You can extract the test values from the C3D samples via the RunTestDataScripts.py (SHARP3D.Test/TestDataExctraction/RunTestDataScripts.py).

The following .JSON file have been corrected by hand due to ezc3d encountering some issues. Bad formatting:

Only two files are missing as they are above the 100 MB limit from Github:
