# EVENT_CONTEXT:ICON_IDS

- **Type**: [Additional](../../additional.md)

- **Locked**: False

This is an unsigned integers array of size \[[EVENT_CONTEXT:USED](./event_context-used.md)\] that identify the icons that an application may associate with each context. 

The ICON_ID parameter can be thought of as a defining the event type or the context in which the event will
be used. (sic. *We will try to provide clarification in the future*)

> If this parameter is used then applications must provide the actual iconic representation.
