# EVENT_CONTEXT:DESCRIPTIONS

- **Type**: [Additional](../../additional.md)

- **Locked**: False

This contains an array of size [EVENT_CONTEXT:USED](./event_context-used.md) containing descriptions (typically up to 32 characters long) that are associated with the corresponding [labels](./event_context-labels.md) e.g. General events, Left side event, Right side event, Invalid event. 

This parameter simply provides additional descriptive information for each of the [LABELS](./event_context-labels.md).
