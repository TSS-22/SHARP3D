# EVENT:DESCRIPTIONS

- **Type**: [Additional](../../additional.md)

- **Locked**: False

This is an array of user defined strings, typically with a size of \[[EVENT:USED](./event-used.md),32\]. It stores a description for each event. This can be a long event definition, for example: “The moment any part of the foot first contacts the floor during a gait cycle”, or a simple descriptive string, for example: e.g. Heel Contact, Cyswllt sawdl, Kontakt pięty, etc.
