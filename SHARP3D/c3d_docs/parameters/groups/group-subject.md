# SUBJECT

It is a parameter group found in many early clinical C3D files that recorded details specific to each trial and session, such as gender, name, date of birth, weight etc.

No other information about this group and its standard parameters are mentionned in the [C3D User Guide](https://www.c3d.org/docs/C3D_User_Guide.pdf).

> It should not be confused with the [SUBJECTS group](./group-subjects.md).
